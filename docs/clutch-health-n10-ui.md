# N10 Health — Clutch (Hilliard Inferno Flame)

Always **setup-tagged**. Read **RPM + speed together**.

## Shop checklist (plain)
1. RPM flares, speed lags → slipping late/too much: cool → clean shoes/drum → then weaker springs or add balanced weights (leading shoes for firmer lock).
2. RPM drops hard / boggy early grab → gripping too early: stronger springs; remove balanced weights; confirm idle below engagement.
3. Heavier/stronger springs = later engagement; lighter/weaker = earlier.
4. Match opposite shoes (spring color, weights, leading/trailing). Never reuse weight snap rings.
5. Needle bearing ≠ bronze bushing: light grease only on needle kit; bronze = one drop light oil — never grease. Keep lube off friction faces.
6. Stop-now: drives at idle, cracked drum, broken spring, blue/purple smoked drum, seized bearing.

## Baseline
~3400 rpm initial contact with 2 white + 2 black, four leading, no weights (contact ≠ lock).
